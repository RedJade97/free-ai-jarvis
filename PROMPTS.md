# Prompts for an evidence-based second brain

Supply the relevant procedure and evidence first. Prompts do not install tools, grant account access or make unavailable data visible.

## Capture

```text
Follow procedure 01-capture using only facts I supply. Format an import using the
data reference and examples. Preserve source IDs, paired counts and timestamps.
Keep unknown values null. Flag missing media, labels and time maps for my review.
```

## Review

```text
Follow procedure 02-review. Account for each supplied evidence ID and whether you
can inspect its complete media. Separate measurements from hypotheses. Propose
KEEP / CHANGE / CUT with timestamps and test metrics. Include counterexamples,
distribution differences and missing inputs. Say cannot tell when appropriate.
```

## Form a lesson

```text
Propose a falsifiable lesson, scoped to this platform and distribution cohort.
Define an observable feature to label before viewing metrics and a prospective
test rule. Start it as a hunch. Sibling cuts and the discovery dataset are not
independent future confirmations. Show what would contradict the claim.
```

## Weekly learning

```text
Follow procedure 03-learn. Account for every lesson in the supplied export.
Explain recorded results, exclusions and counterexamples. Do not claim to have
run tools you did not run. Challenge the strongest pattern. Finish with up to
three next tests and what would make us abandon each hypothesis.
```

## Optional spoken briefing

```text
Explain the approved report conversationally using only supplied evidence.
Distinguish observations, hunches, supported associations and contradicted lessons.
End with the tests I selected. Do not claim an audio file exists without a verified
generation result and playback check.
```
