# Prompts you can use today

Load your memory file and assistant instructions first. These prompts do not grant tools or access that your app does not have.

## Morning plan

```text
Read my current priorities and active projects. Suggest three realistic actions
for today, explain which matters most, and ask about any missing deadline.
Use only the context available to you.
```

## Brain dump

```text
I'm going to talk through several ideas. Let me finish, then organise them into
facts, possibilities, decisions and next actions. Do not treat ideas as commitments.
```

## Decision support

```text
Help me compare these options against the constraints in my memory file.
Explain the tradeoffs and identify the missing fact most likely to change the choice.
```

## End-of-day memory update

```text
Summarise today's confirmed decisions and next actions. Propose an updated
MEMORY.md and list changes separately. Leave out speculation and credentials.
I will review and save it.
```

## Weekly cleanup

```text
Review this memory file for stale dates, contradictory facts and completed work.
Ask me about uncertain items. Suggest a shorter version without discarding
important decisions or their sources.
```

## Move to another assistant

```text
Help me prepare a portable context file for another assistant. Use only the
information visible in this conversation and supplied files. Include preferences,
active projects, confirmed decisions and open questions. Flag anything I should
review before sharing with another provider. Do not claim this exports hidden memory.
```
