# Capture and reconcile

Purpose: turn supplied material into traceable evidence without inventing facts.

1. Confirm the objective, source permissions and experiment ID. Read the existing plan before creating a new one.
2. Inventory every supplied source with a stable ID. Distinguish master media, actual cut, platform post and observation.
3. Preserve publication time, observation time, platform and distribution cohort. Keep counts from the same source response together. Unknown stays unknown.
4. Record feature labels before inspecting performance; do not backdate labels. If the user has already seen results, call that exploratory and use new material for prospective validation.
5. Inspect complete media only if tools and files are actually available. Record speech, screens and original-to-cut mapping. Show missing coverage explicitly.
6. Format an import using the data reference, or write evidence notes for the no-code route. Present uncertain fields for review. Never mark media verified merely because another assistant said so.
7. Reuse existing IDs for identical facts. Add dated observations without overwriting old measurements. Explain conflicts rather than forcing an import.

Completion evidence: source inventory, imported IDs or saved notes, dates and coverage gaps. A proposed file is not a saved or imported record until the action is confirmed.
